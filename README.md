# IRONFRAME — Android Tank Builder / Combat Prototype

**Version track:** v0.1.0 prototype source + cloud build pipeline. This is an original near-future tank construction/combat prototype, not a finished commercial simulator. All prototype meshes are generated from built-in primitives; gun/engine audio is synthesized at runtime. No copyrighted game assets/code/audio/UI are included.

## Primary release pipeline

This project is configured for GitHub Actions + GameCI. Once the one-time GitHub and Unity licensing secrets are configured, CI builds a signed ARM64 APK and AAB, calculates SHA-256 hashes, and publishes versioned files and stable download filenames to GitHub Releases on successful `main` builds, manual runs, and explicit `v*` tags. See [`CI/RELEASE-SETUP.md`](CI/RELEASE-SETUP.md).

Unity cannot be compiled in this delivery environment because the Unity Editor and Android Build Support modules are unavailable here. No APK/AAB or device test is claimed in this source handoff. The CI files are included to perform the actual cloud builds after licensing and signing secrets are configured.

## APK availability

This download is the **source + cloud build pipeline**, not an APK. No fake APK is included.

## Engine / Android baseline

- Unity `6000.3.24f1` (Unity 6.3 LTS); URP `17.3.0`.
- Minimum Android API 29; target API 36 for current Play Store policy.
- ARM64 / IL2CPP; landscape; Vulkan primary with OpenGL ES 3.2 fallback.
- Runtime-procedural low-poly test range, no real-time shadows, unlit material fallbacks, pooled projectiles, 50 Hz fixed timestep and adaptive render-scale script.

## Playable prototype scope

- **Garage:** modular hull, turret, gun, mantlet, left/right track modules, road-wheel count, engine, transmission, fuel/ammo records, addon armor/smoke/fuel modules, armor adjustment, snap movement, approximate mass/center of mass and JSON blueprint save/load.
- **Vehicle:** simplified differential-track Rigidbody driving, aim traverse/elevation, recoil and gravity-affected projectile with pooling.
- **Combat:** game-tuned kinetic penetration estimate, directional armor, module condition, vehicle health and destruction.
- **AI:** one hostile target with simple acquisition, range-based movement, alignment and fire; basic cover checks.
- **Modes:** test range, sandbox and timed single-target mission.
- **Controls:** landscape touch UI for drive/steering, turret and gun aim, firing, build/save/load, modes, settings and LAN.
- **LAN:** host-authoritative UDP snapshots and inputs, direct IPv4 join, max four human tanks including host. Devices must share Wi-Fi/hotspot and be allowed to communicate. Multicast discovery is intentionally omitted; enter host IPv4 manually.

The v0.1 code does not yet include full track-belt/suspension dynamics, a realistic multi-shell ballistic suite, detailed crew hitboxes, walkable interiors, seat possession, human-like AI crew, online matchmaking/Relay, PvP session browser, packet authentication/encryption, advanced prediction, or complete multi-mission campaign. Do not treat the simplified penetration estimate as real armor engineering data.

## One-time project setup

To inspect/edit source, open the `Ironframe` folder in Unity `6000.3.24f1` or a compatible newer LTS editor and allow URP 17.3.0 to resolve. The minimal startup scene is already committed and registered in Build Settings; the arena is generated by `IronframeBootstrap` at runtime. The Android build preprocessor configures URP settings, assets, ARM64/IL2CPP, API 29/36, LAN permissions and graphics API order.

### Controls

- Left lower area: forward/reverse and steering.
- Right lower area: aim and fire.
- Top-right: BUILD, LAN PLAY, MODE, SETTINGS and RESET.
- LAN host: tap HOST SESSION and share the displayed local IPv4 address.
- LAN client: enter host IPv4, tap JOIN HOST. Both phones must be on the same Wi-Fi/hotspot, using UDP port 27840.

## Performance claims

Intended for Snapdragon 685 / Adreno 610 / 4 GB RAM at 720p landscape. **No FPS, memory, cold-start, draw-call, thermal, Vulkan/GLES or profiler result has been measured on that device.** The procedural prototype is deliberately lightweight, but budgets are only confirmed by a real build and device captures.

## Security

Never commit a `.keystore`, Unity license, passwords or base64 keystore to source control. A separate signing kit is delivered outside this source ZIP. Configure the values as repository secrets exactly as described in `CI/RELEASE-SETUP.md`. Back up the keystore securely; future APK updates must use the same key.
